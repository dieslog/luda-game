# Гра в числа

Класична головоломка з числами 1–19 (без 10), записаними цифрами в дев'ять колонок.
Закривайте пари **сусідніх** клітинок (по горизонталі чи вертикалі), якщо числа
**однакові** або дають у сумі **10**. Коли ходів не лишилось — «Дописати»: усі
незакриті числа дописуються в нові рядки. Мета — закрити все поле якомога меншою
кількістю рядків.

Чистий JavaScript/CSS без збірки й залежностей — відкривається просто з `index.html`
або з будь-якого статичного сервера.

## Можливості

**Режими**
- **Нова гра** — класичний порядок `1–9, 11–19`.
- **Згенерувати рівень** — ті самі числа у випадковому порядку.
- **Щоденний виклик** — один і той самий рівень для всіх на сьогодні (рівень генерується
  з дати), з лічильником серії днів поспіль.

**Геймплей**
- Рекорд = найменша кількість рядків, за яку пройдено гру.
- Рахунок і комбо (пара — 10 очок, комбо до ×5 за 6 с, бонус за закритий рядок).
- Таймер гри (ставиться на паузу в меню та коли вкладка прихована).
- Підсвітка «ходів немає»: кнопка «Дописати» починає пульсувати.
- Підтвердження «Дописати», поки ще є ходи; підтвердження перед втратою незавершеної гри.
- Підказка з автопрокруткою до пари; «Є ще?»; безліміт «Назад».
- Опційна підсвітка можливих партнерів вибраної клітинки.
- Автозбереження після кожного ходу + ручний чекпоінт; гра продовжується з меню.

**Прогрес**
- Статистика (перемоги, час, комбо, по режимах, серія днів).
- 17 досягнень з тостами та списком на екрані перемоги.
- Екран перемоги: конфеті, мелодія, рахунок що «накручується», кнопка «Поділитися».

**Комфорт**
- Світла / темна / авто тема, налаштування звуку (гучність), вібрації, кольорів клітинок.
- Керування з клавіатури (див. нижче), ARIA-розмітка, `prefers-reduced-motion`.
- PWA: встановлюється на телефон і працює офлайн.

## Клавіатура

| Клавіші | Дія |
|---|---|
| ← ↑ ↓ → | курсор по відкритих клітинках |
| Enter / Пробіл | вибрати клітинку |
| Z / Ctrl+Z / Backspace | назад |
| H | підказка |
| R | дописати |
| C | чи є ще ходи |
| M / Esc | меню |

## Структура

```
index.html            розмітка: меню, HUD, поле, модалки
css/main.css          стилі на CSS-змінних (світла/темна тема)
sw.js, manifest.webmanifest   PWA
js/
  util.js             $-хелпери, шина подій (LG.bus), toast, confirm, formatTime
  rng.js              детермінований ГПВЧ (щоденний виклик)
  storage.js          весь localStorage (ключі lg.*)
  settings.js         налаштування + тема
  audio.js            звуки (mp3 + синтез Web Audio), гучність
  confetti.js         canvas-конфеті
  board.js            числа рівня, рендер, пошук сусідів/пар, знімки
  timer.js            ігровий годинник із причинами паузи
  score.js            очки та комбо
  stats.js            статистика, щоденний журнал, серія
  achievements.js     досягнення
  feedback.js         звук/вібрація/«+10» у відповідь на події гри
  hud.js              верхня панель і комбо-чіп
  preview.js          закріплений рядок найближчих клітинок, відступи
  game.js             контролер гри (стан, ходи, undo, дописати, перемога)
  victory.js          екран перемоги
  menu.js             меню та підекрани
  main.js             запуск, клавіатура, життєвий цикл
```

Модулі спілкуються через шину подій: `game.js` лише емітить (`match`, `error`,
`rewrite`, `undo`, `hint`, `win`, …), а звук, статистика, досягнення й HUD підписуються
незалежно.

## Запуск

Просто відкрийте `index.html`, або з терміналу:

```bash
python -m http.server 4599
```

Service worker (офлайн/встановлення) працює лише на `localhost` або по HTTPS.
